# Source Documents

本目录记录项目初始化使用的源材料。当前没有复制原始 Word 文档到仓库，仅记录来源和作用。后续如果要长期保存，应把脱敏后的稳定版本放入仓库。

## 源材料

| 文件 | 来源 | 用途 |
| --- | --- | --- |
| PRD | 项目资料包 | 一期需求、角色权限、状态、工艺流、数据库字段、页面、验收标准、API 摘要 |
| OpenAPI | 项目资料包 | 后端接口契约，已修复后放入 `docs/api/openapi.yaml` |
| 生产流程 | 项目资料包 | 客户提供的 9 类牙科产品生产工艺路线原始数据 |
| 团队执行与协作文档 | 项目资料包 | 开发工程师职责、里程碑、Git/PR、验收推进方式 |
| TRD V1.1 深度研究优化版 | 项目资料包 | 当前开发计划修订依据；明确模块化单体、轻量 DAG、状态投影、文件上传默认方案、AI 工具白名单、通知事实来源、专项验收矩阵 |

## 当前优先依据

任务拆解和技术执行口径以 TRD V1.1 深度研究优化版为准；PRD 一期范围仍是范围边界。深度研究中属于实现方式、数据一致性、安全边界、测试验收的内容纳入一期；属于新增功能、复杂平台或二期演进的内容不进入一期开发。

## 源材料风险

- 本地资料包路径可能因转发、下载或开发机环境变化而失效。
- 开发前建议把确认后的 PRD、TRD、OpenAPI、生产流程整理为稳定脱敏版本。
- 不要提交包含密钥、真实客户隐私或真实医疗数据的材料。
