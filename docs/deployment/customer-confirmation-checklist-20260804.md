# 上线前客户确认清单

状态：ACTIVE / 2026-08-04

面向客户的确认项汇总。按**谁能回答**分组，避免把技术问题问到业务负责人头上。
既有的 PRD 层面确认项见 `docs/acceptance/phase-one-customer-pm-confirmations.md`，本清单不重复。

## 一、问装机的人 / IT（阻塞部署开工）

| # | 问题 | 为什么要问 | 怎么拿到答案 |
| --- | --- | --- | --- |
| IT-1 | 服务器有几块硬盘、每块多大、固态还是机械、有没有做 RAID 冗余 | 决定虚机磁盘怎么分、备份放哪。系统单个文件上限 500MB（口扫 STL 模型），数据只增不减 | 打开「此电脑」截图；或问当初装机/供货的人 |
| IT-2 | BIOS 里的虚拟化（Intel VT-x / VT-d）有没有打开 | 部署需要开 Hyper-V，虚拟化关着就开不了。**打开要重启进 BIOS，得约时间** | 我们远程连上后可以自查，查出来是关的需要现场配合 |
| IT-3 | Windows 未激活，打算怎么处理 | 不激活拿不到安全更新，且会持续弹提示 | 客户自行处理或联系供货商 |
| IT-4 | 服务器是不是固定 IP，网络怎么接的 | 诊所要访问这台机器 | 问网管 |
| IT-5 | 有没有 UPS（不间断电源） | 这台机器要当服务器 7×24 开着，断电会丢正在处理的事务 | 看机房/机柜 |

## 二、问业务负责人（阻塞方案定型）

| # | 问题 | 为什么要问 |
| --- | --- | --- |
| BIZ-1 | 这台服务器**只跑我们这套系统**，还是上面还有别的软件在用？ | 只跑我们的，可以直接装 Linux，更省事也更稳；还有别的软件就在 Windows 上加一层虚机 |
| BIZ-2 | 诊所的医生从**哪里**访问？只在工厂局域网内，还是外面的诊所也要用？ | 外面要用就得有公网 IP 或专线、端口映射、域名，可能还涉及备案，工作量差别很大 |
| BIZ-3 | 有没有已经买好的**域名和 HTTPS 证书**？没有的话由谁买？ | **医生端要上传患者资料和病例照片，明文 HTTP 不能上线。** 这是硬门槛 |
| BIZ-4 | 远程部署用什么方式接入？向日葵 / ToDesk / VPN？ | 我们要远程连上去装，部署期间可能反复重连 |
| BIZ-5 | Windows Server 2016 的官方支持 **2027 年 1 月到期**，之后不再有安全更新。是否计划升级？ | 不影响这次上线，但需要客户知情并有计划 |

## 三、上线前必须提供的业务数据（不给就只能用占位值）

**这一组最关键的是 DATA-1。** 系统会给医生算出具体的预计到货日期，现在用的是暂定值，
界面上标了「待确认」——但只要有人截图或口头转述，那三个字就掉了，剩下一个看起来像承诺的日期。

| # | 数据 | 影响 | 不给会怎样 |
| --- | --- | --- | --- |
| DATA-1 | **各类产品的标准制作周期**（如：全瓷冠几天、支架义齿几天、隐形矫治器几天） | 交期计算引擎 | 用暂定值算交期，显示「待确认」。**建议在拿到前不要对外使用交期功能** |
| DATA-2 | 快递、业务员配送各自的**在途天数** | 到货时间 = 制作完成 + 在途 | 同上 |
| DATA-3 | 医生多久不回复过程确认算「拖太久」（现在暂定 2 天） | 超时后订单进等待状态并顺延交期 | 按 2 天走 |
| DATA-4 | 真实的**部门 / 班组 / 岗位清单** | 组织架构、派工、绩效归属 | 现在是演示数据（CAD 设计组、切削加工组等） |
| DATA-5 | 真实的**人员名单**及各自角色 | 账号与权限 | 无法开账号 |
| DATA-6 | **产品价格** | 账单与报价 | 全部显示「待报价」 |

DATA-1 / DATA-2 / DATA-3 都在管理端配置页里改，**不用改代码、不用重新发版**。

## 四、规则口径确认（不阻塞上线，但会影响最终形态）

这几条是之前几批开发中发现的、客户确认表里没写清或自相矛盾的地方。
我们都做成了**可配置**，先按保守口径运行，客户回复后改配置即可。

| # | 问题 | 我们当前的处理 |
| --- | --- | --- |
| RULE-1 | 「高级客服」到底保留还是取消？（确认表里两个框都打了勾） | 先保留，开关 `role.cs-senior.enabled = true` |
| RULE-2 | 管理端能不能代替技工操作生产？能到什么程度？（客户否决了「不能」的建议但没写允许范围） | 先关闭，开关 `role.admin.can-operate-production = false` |
| RULE-3 | 「生产资料审核员」取消后，由部门主管还是生产经理承接？ | 先给部门主管，开关可改 |
| RULE-4 | **哪些订单类型需要填回寄运单号？** 任务书里两处写法不一致：一处写「返工/退货/仅设计」，一处写「印模/返工/退货」 | 按后者（印模/返工/退货）——仅设计订单不寄实体模型，要求运单号会拦住正常下单 |
| RULE-5 | 「只能由管理者账号导出」——是**所有导出**都只能管理者做，还是只有敏感数据（客户信息/地址/账单/价格）需要？ | 按后者：敏感数据只有管理员/经理能申请且需他人批准；其余数据各管理端可导出并留痕。医生端一律不能导出 |
| RULE-6 | 医生下载**自己的单张账单 PDF**，算不算「导出」？ | 暂时保留（是单据下载不是数据导出，且当前接口恒返回空列表）。客户认为算的话可以一并收掉 |

## 五、我们这边不需要客户确认、直接执行的

列在这里是为了让客户知道我们会做，不用他们操心：

- HTTPS 配置、备份脚本与恢复演练、基础监控
- 服务器上的 Hyper-V 与 Linux 虚机搭建
- 超级管理员账号由客户本人现场设置密码，**我们不留后门账号**
- 数据库迁移与初始化（不灌演示数据）
