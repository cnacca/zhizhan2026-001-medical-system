# 第 2b 课：权限边界补充

## 为什么客服不能把内部原文直接发给医生

内部原文可能包含员工姓名、责任归因、质检记录和未确认判断。直接外发会造成隐私泄露、责任争议或错误承诺。客服应把它转换成经过审核的客户表达，例如“订单正在进行质量复核，完成后将继续生产”。

## “不能相互干涉”如何落成系统规则

- 数据范围：生产人员 A 不能读取 B 的任务。
- 操作权限：A 不能替 B 开工、完工或修改记录。
- 字段权限：A 不能读取 B 的绩效和责任归因。

后端应拒绝越权请求，返回 403 或空数据，不能只隐藏前端按钮。

## 不懂牙科也能做产品判断

只要确认三点：客户现在处于什么阶段、是否影响交付、客户是否需要采取行动。无需先掌握每个专业工序。

## 检查站

1. 客户问“为什么订单延期”，为什么可以说“正在质量复核”，但不能直接说出技工姓名和责任判断？
2. 生产人员 A 不能查看 B 的任务，也不能替 B 完工。前者和后者分别属于哪类权限？
3. 作为产品经理，看到“订单正在处理异常”时，为什么应先确认客户是否需要做什么，而不是先追问具体牙科工艺？

请用日常语言回答，不需要牙科术语。
