# 管理端订单管理页设计与验收记录

- 日期：2026-07-16
- 状态：高保真原型已获用户确认，正式 Vue 实现与真实 Chrome 验收已完成
- 范围：管理端“订单列表”与“文件资料”，不含工作台业务内容

## 当前设计门禁

- 列表页唯一视觉母版：医生端“我的案例”。
- 详情唯一视觉母版：生产端“工作单”。
- 生产端“生产订单”只补充客户/患者编号、牙位、技师、交期和审核标记等字段，不建立第三套布局。
- 主列表只保留管理员快速判断所需字段；牙位、技师、材料、色号、完整审核标记和流程链进入详情抽屉。
- 当前接口缺少的创建时间、更新时间等字段保留视觉位置并显示“暂未提供”。
- 详情采用 820px 只读抽屉；像素级复刻以抽屉内部组件比例、信息层级和交互节奏为准。
- 静态原型已通过用户视觉确认；正式实现严格沿用该结构并绑定真实数据。

静态原型：`prototype/order-management-hi-fi.html`。原型内标记为“视觉样例”的多行内容仅用于验证表格密度，不进入正式实现。

## 实现口径

| 管理端区域 | 直接参考 |
| --- | --- |
| 筛选面板、日期结构、快速筛选 | 医生端“我的案例” |
| 状态标签、阶段点阵 | 医生端订单表 |
| 客户/患者编号、牙位、技师、交期、审核标记 | 生产端“生产订单” |
| 详情抽屉、订单信息和流程链 | 生产端“工作单” |
| 整体颜色、导航和页面框架 | 冻结的管理端蓝色规范 |

- 订单筛选按医生端参考页重构为状态、医生、客户、产品、关键字和快速筛选层级。
- 创建日期与交期筛选结构保留；当前只读列表接口未提供完整日期字段时明确显示“暂未提供”，不删除结构、不伪造数据。
- 订单主表按医生端母版展示订单编号、客户/患者、产品/牙位、医生状态、生产阶段、交期、审核标记和更新时间；技师、材料、色号等完整生产字段进入详情抽屉。
- 医生可见状态与内部生产阶段分开表达；阶段点阵来自真实订单状态，真实工序节点按需从现有接口读取。
- 筛选条件、列表、分页和详情抽屉均使用真实接口数据。
- 详情抽屉为只读查看模式，不承载客服、生产、账单或物流操作。
- 文件资料按真实订单聚合；无文件和设计稿时展示真实空状态，不生成示例数据。
- 后端未提供的更新时间明确显示“暂未提供”，未推断或伪造时间。

- `npm run build:frontend`：通过。
- 真实 Chrome 1440×900：订单列表、快速筛选、关键字筛选、重置、详情工作单、Esc 关闭、文件资料切换通过；页面无横向或纵向溢出。
- 真实 Chrome 1280×800：11 列订单列表完整显示，页面与表格均无横向或纵向溢出。
- 可见状态已统一为中文，真实 `DRAFT` 状态显示为“草稿”。

以上结果只能证明旧实现可构建、可交互，不能证明视觉复刻通过。

## 高保真原型验证结果

- 参考文件 SHA-256 与冻结基线一致。
- 真实 Chrome 目标视口为 `1440×900`；原型实际截图为 `1440×900`，无页面级横向或纵向滚动。
- 医生端参考受 Chrome 固定滚动条影响，实际截图为 `1435×897`；生产端工作单参考实际截图为 `1436×898`，文件名中的 `1440×900` 表示目标视口。
- 列表筛选卡底部为 `496px`、表格顶部为 `510px`；医生端参考在同目标视口中的对应位置约为 `511px`、`526px`，首屏节奏已对齐到同一结构层级。
- 已验证快速筛选选中态、关键词输入与清除、点击订单打开抽屉、`Esc` 关闭、遮罩关闭路径。
- 原型 DOM 尺寸为 `1440×900`，`scrollWidth=1440`、`scrollHeight=900`。
- 页面自身没有控制台错误；仅记录到 Chrome 扩展的普通日志。

设计技能复核（相对本轮静态原型 brief）：视觉层级 9/10、字体 8/10、颜色与对比 9/10、间距与节奏 9/10、动效与微交互 8/10、文案与叙事 9/10，总分 52/60，达到提交视觉确认门槛。反 AI 模板化检查未命中需要返工的模式。

## 正式实现验收结果

- 正式列表已替换为 10 列医生端母版结构；生产端信息作为字段补充，没有再建立第三套布局。
- 详情已替换为生产端工作单结构的只读抽屉：1440 视口宽度 `820px`，1280 视口宽度 `780px`。
- 正式页面只展示真实接口订单；没有把原型中的“视觉样例”写入业务数据。
- 创建日期、更新时间及当前接口未提供的字段保留位置并显示“暂未提供”；没有伪造时间或业务结果。
- `npm run build:frontend`：通过。
- `git diff --check`：通过。
- 真实 Chrome `1440×900`：页面 DOM 为 `1440×900`，列表容器宽 `1159px`、滚动宽 `1159px`，无页面或表格横向溢出。
- 真实 Chrome `1280×800`：页面 DOM 为 `1280×800`；表格容器宽 `1011px`、内容宽 `1080px`，仅表格内部按参考结构横向滚动，整页无横向溢出。
- 已验证关键词空结果、清除全部、快速筛选、刷新、点击整行/“查看”按钮打开详情、`Esc` 与自定义关闭按钮关闭、订单列表/文件资料切换。
- 抽屉正文在两个视口下均满足 `clientWidth=scrollWidth`，无内部横向溢出；默认重复关闭按钮已移除。
- 文件资料继续使用真实订单、附件和设计稿接口；当前样本无附件时显示真实空状态。
- Chrome 控制台没有应用错误；仅有浏览器扩展普通日志与 Vite 连接/热更新调试日志。
