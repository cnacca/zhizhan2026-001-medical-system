## 1. 本轮范围

本轮连续完成客户管理、账单配送、外协管理、工艺生产、质量管理、绩效统计、设备管理、物料异常、安环管理、成本管控、产品总览、通知中心和智能服务共 13 个管理端页面。人员管理 V2、订单管理和沟通中心保持既有验收基线。经用户后续确认，工作台仅调整顶部视觉、指标口径及接单/出货月度对比，不改变其他经营内容。

本轮在独立数据库 `ai_order_platform_demo` 中补齐可重复恢复的脱敏业务数据，并为设备、物料异常、安环、成本和外协补齐真实列表、详情与允许的状态流转。数据经真实接口读取和写入，不使用前端 fixture，不向主展示库造数，也未增加假成功或权限绕过。

## 3. 真实浏览器验收

使用管理员现有登录状态，在真实 Chrome 中从侧边栏逐页进入；未通过修改路由或直接调用接口替代用户操作。

### 3.1 尺寸与滚动边界

- `1440×900`：新页面主内容根区域宽度 1162px，左右各 24px；页面整体无横向滚动。
- `1280×800`：新页面主内容根区域宽度 1014px，左右各 18px；页面整体无横向滚动。
- 宽表格只在表格容器内横向滚动；绩效表格已实际拖动验证。
- 详情抽屉宽度约 560px，订单管理既有专属抽屉保持 820px；抽屉正文独立滚动。
- 两个尺寸均检查遮挡、溢出、错位、文字截断、异常留白和抽屉滚动边界。
- 智能服务趋势区精修后在 `1440×900` 固定为 340px、在 `1280×800` 固定为 326px；两种尺寸均无页面横向滚动，风险矩阵、预算卡和七日日期轴无截断。悬停真实数据点可查看日期、调用次数和预计费用。

### 3.2 操作路径

- 实际点击侧边栏导航与展开/收起，逐页进入全部 13 个目标页面。
- 实际操作主/次页签、搜索、筛选、清空、刷新、排序、分页可用状态、行点击及抽屉打开/滚动/关闭。
- 通知中心实际完成“未读 2 -> 单条已读 -> 未读 1 -> 全部已读”，随后重新执行受保护播种恢复为 2 条未读。
- 浏览器刷新后进入安全入口，重新登录管理员账号后可返回管理端页面。
- 使用浏览器网络拦截模拟一次产品数据加载失败，页面显示“数据暂时无法加载，请稍后重试”；取消拦截并点击重试后恢复真实列表。
- 管理员账号无法自然触发无权限分支；前端已将 403 映射为“当前账号无权查看此业务内容”，本轮不据此宣称经理/主管权限矩阵已经验收。
- 逐页检查控制台和网络请求，未发现本轮页面持续报错、失败请求、重复请求风暴或鉴权异常。

### 3.3 冻结页面回归

- 人员管理 V2：列表、筛选区和既有布局在两个尺寸下正常。
- 订单管理：两行筛选和 820px 专属详情抽屉保留，未复制到其他页面。
- 沟通中心：消息/管理页签、会话区及既有交互正常。
- 工作台：顶部标题区与客户管理等管理页统一为 80.8px 基线，标题使用 `#0f172a`、23px 和统一字体；移除重复的“管理经营驾驶舱”说明区；“出货份数/异常率”替换为“待发货订单/订单完成率”，“当日效率统计”调整为“本月运营效率”，金额图按本月截至今日与上月同期展示真实累计趋势。

- 当前新增数据属于本地隔离演示数据，不代表客户真实生产数据已经接入。

- 本轮只验收管理员视角，不代表经理或主管权限已经完整支持。
- 设备审批、物料/安环状态更新、成本确认和通知已读可在演示库实测；不得在主库为了演示制造记录。
