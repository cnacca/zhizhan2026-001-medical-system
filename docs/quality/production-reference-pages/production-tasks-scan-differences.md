# 我的任务与扫码登记 1440px 对比记录

- 对比时间：2026-07-12
- 验收视口：1440 × 900
- 参考映射：Work Orders → 我的任务；Scan & Check-in → 扫码登记

说明：参考 Work Orders 页面在 1440×900 浏览器视口下因原型页原生滚动条导出为 1436×898 像素，实际浏览器视口已确认是 1440×900；其余三张截图均为 1440×900。

## 已对齐项

- 我的任务采用紧凑任务卡：订单号、工序、节点、标准时长、状态和操作按钮同层展示。
- 扫码登记采用参考式定位输入区与左右工作区：左侧真实任务列表，右侧检查表单与历史记录。
- 无摄像头、硬件扫码或模拟扫码结果；定位仅调用当前账号可读取的真实任务列表。
- 开始工作、标记完成、入检、出检和返工提交继续使用原有接口与权限控制。

## 已验证交互

- 生产账号进入“我的任务”后加载 118 条待开工真实任务，并显示可用与禁用操作状态。
- 生产账号进入“扫码登记”后输入真实订单号，定位到节点 6583 与对应检查表单。
- 未执行开始任务或提交检查，避免改动现有生产记录。

## 剩余视觉差异

| 差异 | 原因 | 后续处理 |
| --- | --- | --- |
| 参考工作单为可打印纸张式布局，当前任务页为工序卡 | 当前接口只返回当前任务节点，不返回完整工单字段 | 接口补充工单字段后再增加打印式详情 |
| 参考扫码页有责任审计区 | 当前扫码接口不提供该类独立数据 | 不伪造记录；继续保留真实检查历史 |
| 任务卡缺少交期和患者标识 | 当前任务接口未返回 | 后续字段可直接加入卡片信息槽 |
