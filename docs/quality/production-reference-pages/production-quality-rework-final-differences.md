## 对比结论与剩余差异

1. 已统一为参考页的浅灰内容底、白色分组卡、14px 圆角、低对比边框、青绿色主操作色、紧凑标题层级和固定桌面双栏布局。
2. 左侧菜单仍完全使用原项目的菜单结构、路由和权限逻辑；因此侧栏的分组和账户区不按参考静态页面重做，这是保留业务边界的有意差异。
3. 质量总览的投诉率、退货率若接口字段缺失显示“暂无统计”；当前接口实际返回数值时仍展示真实百分比。参考页中的静态示例数字不复刻为假数据。
4. 内返管理保留了原有的终检入口，便于维持既有操作路径；终检报告菜单同时提供独立的聚焦页面。后续若允许重构组件，可将内返页面中该入口收敛为跳转按钮，以进一步缩短首屏。
5. 外返登记、状态更新、终检提交和返工关闭均连接既有真实接口。验收中未执行写入动作；参考页中没有对应后端能力的纯展示入口，未伪造状态或数据。
6. 当前真实数据量较大，部分记录的订单号、节点号和原因内容比参考示例更长；已通过横向布局、换行和滚动保持桌面首屏完整，仍会比参考静态数据密度更高。
