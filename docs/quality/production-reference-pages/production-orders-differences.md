# 生产订单页 1440px 对比记录

- 对比时间：2026-07-12
- 验收视口：1440 × 900
- 参考页：`frontend/public/reference/factory-portal.html` 的 Production Orders
- 实现页：生产端 → 生产订单

## 已对齐项

- 同步信息条、紧凑顶部栏、页面标题、筛选标签、搜索、批量选择和打印入口。
- 白底圆角表格容器、浅灰表头、细分隔线、紧凑行高、青绿色订单编号与状态标签。
- 订单行点击右侧抽屉；抽屉提供真实订单信息、工序时间线、文件操作和联系客服入口。
- 订单页与生产看板共用原有订单查询、详情、文件、工序和消息能力；未新增模拟数据或接口。
- 缺失字段稳定显示“待分配”“未设置”“暂无记录”，不以零值或技术提示替代。

## 已验证交互

- “待发货”筛选：50 条真实订单中筛出 8 条。
- 勾选订单后，“打印已选”由禁用变为可用。
- 点击订单打开详情抽屉；工序、文件和联系客服操作入口可见。
- 生产看板结构检查与前端构建均通过。

## 剩余视觉差异

| 差异 | 原因 | 后续处理 |
| --- | --- | --- |
| 侧栏品牌、菜单图标和用户区与参考不同 | 按已确认边界，保留现有菜单结构和 SVG 图标 | 不调整 |
| 参考页含患者编码、试戴与审核标记；实现页未显示 | 当前生产订单接口未提供这些可安全展示的独立字段 | 新字段可用后直接填入现有表格槽位 |
| 参考页有更多静态阶段筛选标签 | 实现页仅使用真实可判断的全部、异常、待发货、待确认状态 | 后续接口提供稳定阶段口径后增加真实筛选 |
| 参考页行末有独立“查看”按钮 | 实现页采用整行打开抽屉，保留更大的可点击区域 | 当前交互已满足，暂不追加重复按钮 |
