# 人员、生产支持、沟通与云端页面差异记录

## 对比依据

- 视觉与交互基线：`frontend/public/reference/factory-portal.html`
- 参考截图：`factory-portal-reference-1440.png`
- 实现截图：本目录下各 `production-*-implementation-1440.png`
- 视口：1440×900

## 已对齐

- 统一采用参考页的浅灰内容底、白色圆角卡片、细边框、低阴影、紧凑页头、青绿色主操作和可横向滚动表格。
- 员工、绩效、奖惩、设备、物料、安环、成本、外协、沟通和云端文件均有独立内容结构，不再只是旧页面套壳。
- 外协成本强制使用真实 `OUTSOURCING` 成本类型；沟通中心保留现有客服审核链路；云端数据只复用实际订单附件与短时效预览能力。
- 页面不再显示内部绩效规则版本、`PARTIAL`、`本地第一增量`、`工序待同步` 或 `工序待映射` 等技术文案。

## 剩余差异

| 页面组 | 差异 | 原因 | 后续数据到位后的表现 |
| --- | --- | --- | --- |
| 员工与绩效 | 员工卡仅 1 张，工时明细以真实记录为准 | 当前生产账号可访问的人员数据有限 | 新增员工和工时后自动扩展卡片/表格。 |
| 奖惩、设备、物料、安环 | 参考页的多行台账未出现 | 当前接口没有对应真实明细或返回为空 | 保持统一空态，不伪造记录；真实记录接入后直接渲染。 |
| 成本与外协 | 不展示参考页中的合作工厂、供应商演示信息 | 这些内容不属于现有真实业务数据 | 成本记录和真实供应商字段返回后直接展示。 |
| 沟通中心 | 未输入订单时没有会话列表和客服回复 | 会话严格基于可访问订单消息 | 输入订单后加载真实上下文和可 @ 人员。 |
| 云端数据 | 首屏为空文件状态 | 当前生产账号无可访问附件 | 选择有附件订单后使用现有短时效预览/下载地址。 |

以上均为真实数据差异，不是视觉降级；页面结构、留白、层级与空态保持完整。
