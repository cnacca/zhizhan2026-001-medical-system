# 客服端交互行为基线

- 侧栏切换：更新业务页面，顶栏壳层不跳动；当前项唯一高亮。
- 筛选：只改变真实结果集；当前详情不在结果内时关闭详情。
- 表格行：订单、设计、产品、账单、配送、外协点击后打开 `540px` 右抽屉；客户点击后打开 `860px` 连续滚动详情弹窗；关闭后回到原滚动位置。
- 详情容器：所有详情内容按业务顺序连续排在同一页，不再使用详情导航页签；保留页面级业务页签和设置页签。
- 订单抽屉：抽屉整体滚动且顶部吸顶；顶部摘要之后依次展示参考式纵向制作时间线、订单资料、文件与设计、订单记录，最底部展示完整订单消息和回复输入框。
- 制作时间线：展示全部真实工序，已完成/进行中/待处理/跳过状态分别使用参考文件的浅紫、实心紫、灰白和低透明度样式。
- 订单抽屉沟通：在同一连续页面中读取真实订单消息，客服可直接发送给医生/诊所；失败保留草稿，不前端假成功。
- 配送登记：详情抽屉仅负责查看和校验，登记物流使用独立 `760px` 弹窗；已发货/已签收不再出现重复登记表单。
- 信息审核/翻译：翻译人员保存/确认；客服只查看关联结果并在问单沟通处理客户疑点。
- 设计稿：客服审核版本；需要客户确认时创建“设计确认”问单，不新增独立菜单。
- 问单沟通：右侧是自由会话，不是固定话术；快捷回复只填入输入框，不自动发送。
- 产品：一期不提供新增产品，只维护已有产品可下单信息。
- 月结：按已确认规则自动生成汇总，授权人员核对/发送；无真实数据时展示空态。
- 通知：已读不等于业务已处理。
- 顶栏搜索/帮助/通知：通过辅助页或弹层进入；返回后保留来源页面状态。
- 所有危险或尚无后端能力的写入按钮保持禁用或明确说明，不用前端假成功。
- 加载失败与真实空数据分开呈现；接口失败时不得退化为“暂无数据”。
