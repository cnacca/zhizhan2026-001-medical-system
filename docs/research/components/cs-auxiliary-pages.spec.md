# CS Auxiliary Pages Spec

Applies to notifications, help and global search.

- no sidebar item; entry is topbar only
- preserve the previously active business menu item
- use the same `22px 26px` content padding, heading block, filters, cards and list rows
- notification read state is visual metadata, not a processed state
- help supports topic switching and keyword filtering without fabricated contact details
- search groups real results by business type; clicking a result navigates to the exact record/drawer when authorized
- empty and permission states are explicit; no copied demo data
