# 客服端页面拓扑

视觉基准为 `frontend/public/reference/cs-portal.html`，业务口径以 `docs/design/cs-portal/` 确认稿为准。

```text
客服端壳层（236px 侧栏 + 56px 顶栏）
├─ 工作台：保留现有主体
├─ 订单管理：筛选 → 表格 → 540px 连续详情抽屉 → 底部订单消息与回复
├─ 信息审核/翻译：任务列表 → 审核编辑区 → 关联问单
├─ 设计稿管理：订单列表 → 540px 版本/审核抽屉
├─ 问单沟通：290px 会话列表 → 自由会话区
├─ 客户管理：筛选 → 两列客户卡 → 860px 连续分区客户详情弹窗
├─ 产品管理：筛选 → 表格 → 540px 只维护详情
├─ 账单管理：单笔/月结筛选 → 表格 → 540px 详情
├─ 配送管理：筛选 → 表格 → 540px 详情 → 760px 发货登记弹窗
├─ 外协管理：筛选 → 表格 → 540px 详情
├─ 设置与账号：页签 → 团队/回复/通知/显示偏好
└─ 顶栏入口
   ├─ 通知中心
   ├─ 帮助中心
   └─ 全局搜索
```

辅助页面不占侧栏菜单项；进入和返回时保留原业务菜单、筛选、选中记录和滚动位置。
