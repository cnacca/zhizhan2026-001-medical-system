# 生产看板标题日期展示设计

**状态：已确认，待实施**

## 目标

让生产人员进入生产看板时，直接从页面标题识别当前查看的生产日期，避免仅依赖右侧日期控件判断看板数据范围。

## 已确认的呈现方式

标题使用以下格式，并随当前看板日期实时变化：

`生产看板 · 2026年7月12日 星期日（今日）`

当查看非当天日期时，移除“今日”标记，例如：

`生产看板 · 2026年7月11日 星期六`

## 方案比较

1. 仅将 ISO 日期显示在标题中：改动最小，但不够易读。
2. 标题显示中文日期、星期和“今日”状态：信息清晰，复用已有日期选择状态，推荐采用。
3. 在标题中再重复展示活跃单、超时单等统计：信息密度较高，且现有标题标签和控制区已覆盖，不纳入本次范围。

## 实施设计

- 在 `frontend/src/App.vue` 中增加一个只读计算值，基于现有 `productionBoardKanbanDate` 格式化为中文年月日和星期。
- 当选中日期与本机当天相同，追加“（今日）”。
- 将该计算值渲染在“生产看板”主标题内，使用分隔点与主标题区分；右侧的活跃单与最后同步标签保持现状。
- 继续复用现有“前一天 / 后一天 / 日期输入 / Today”控件，不改变日期切换、订单加载、筛选或同步逻辑。
- 仅在生产看板路由生效，不影响生产工作台、客服端和其他页面。

## 边界与异常处理

- 日期值应按本地日历日格式化，避免 UTC 转换导致跨时区显示前后一天。
- 若日期输入出现无效值，标题回退为“生产看板”，页面仍由现有日期切换逻辑处理恢复。
- “今日”以客户端当天为判断基准，与现有 `resetProductionBoardKanbanDate` 行为一致。

## 验收标准

1. 默认打开生产看板时，标题显示当天的中文日期、星期和“今日”。
2. 点击前一天、后一天或直接选择日期后，标题立即切换到对应日期与星期。
3. 非当天日期不显示“今日”。
4. 活跃单、最后同步、日期控件和看板列仍正常显示与工作。
5. 前端类型检查和构建通过。
