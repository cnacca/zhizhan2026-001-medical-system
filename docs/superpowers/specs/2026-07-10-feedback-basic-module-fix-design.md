# 旧测试反馈菜单基础能力修复设计

## 目标

修复 2026-07-08 旧测试反馈中 BUG-003 的菜单演示、待接入和接口异常问题。每个受影响入口在当前一期范围内提供真实的基础台账、登记、查询或状态更新能力。

## 已确认边界

- 采用一期基础版，不建设外协供应商结算、扫码硬件集成、云端同步中心或完整 RBAC 管理后台。
- 不以删除菜单、隐藏错误或保留“演示入口”文案作为修复方式。
- 医生端的数据隔离、现有后端鉴权和 Task 8 `NOT_READY` 状态不变。

## 入口映射

| 旧反馈入口 | 一期基础能力 | 复用对象 |
| --- | --- | --- |
| 客服外协管理、管理端外协管理 | 外协成本台账、登记与汇总 | 成本管理接口和页面 |
| 客服生产备注助手 | 订单生产备注草稿与确认 | 内部订单中的 AI 生产备注能力 |
| 生产端扫码登记 | 人工登记工序检查和流转节点 | 检查任务页面；不宣称硬件扫码 |
| 生产端终检报告 | 终检记录、结论和返工关联 | 终检/返工页面 |
| 生产端设备、物料、成本、外协成本、安环、奖惩 | 对应真实汇总、登记和状态更新 | 已有生产辅助模块 |
| 生产端消息中心 | 通知查询与已读状态更新 | 通知中心 |
| 生产端云端数据中心 | 订单设计稿和附件台账 | 内部订单设计稿能力 |
| 管理端用户、角色权限 | 当前账号、角色、菜单和权限清单 | 本地权限清单页 |
| 管理端设备、物料 | 对应真实汇总与基础登记 | 已有生产辅助模块 |
| 管理端账单配送 | 账单与物流查询、状态跟进 | 配送管理页面 |

## 行为与验收

1. 反馈清单中的入口不再配置为 `placeholder`，页面不显示“演示入口”“待接入”或“后续接入接口”的文案。
2. 每个入口打开后展示真实后端数据，或在无数据时展示正常空态；不允许由 `400`、`403` 或前端占位页代替。
3. 具备已有写能力的台账保留其登记或状态更新控件，且仍由服务端权限校验决定是否可操作。
4. 定向 Playwright 用例逐端登录，遍历旧反馈菜单，断言落到基础能力页且没有占位或请求失败状态。

## 风险处理

- 复用页面的标题随点击菜单变化，但数据加载分支必须根据当前菜单 ID 覆盖所有别名。
- 对没有专用后端模型的扫码和云端数据入口，只暴露当前真实存在的人工检查和设计稿附件台账，不新增虚假 API。
- 若某角色访问复用接口被服务端拒绝，按真实权限修复或调整为该角色已有的可访问基础能力，不放宽医生端或绕过鉴权。
