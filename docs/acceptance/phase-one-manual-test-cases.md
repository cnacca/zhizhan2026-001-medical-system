## 0. 执行须知

### 0.1 判定只看事实

- **只记录你实际看到的**。页面没出现的东西就是"未出现"，不要推测"可能是没加载"。
- **失败要留证据**：截图、URL、报错原文、订单号。
- **区分三种失败**：
  - `FAIL-功能` —— 点了没反应、报错、结果不对
  - `FAIL-数据` —— 功能在，但列表为空/没有可操作对象
  - `BLOCKED` —— 前置条件不满足，无法执行

`FAIL-数据` 极其重要，单独标出来。本项目历史上多次出现"功能完好但演示数据缺失"，被误判为"功能没做"。

### 0.2 不要做的事

- **不要点击「同意当前版本」「确认收货」「发布」等会改变演示数据状态的按钮**，除非用例明确要求。用例中标注 `[写操作]` 的才可以点。
- 不要修改产品目录草稿、不要发布配置版本。
- 不要删除任何数据。

### 0.3 已知会失败的项

第 9 章列出了**已知不可测/必然失败**的项目及原因。执行到那些用例时按第 9 章的说明判定，不要当成新发现的缺陷。

## 1. 环境准备

### 1.1 启动

在仓库根目录执行：

```bash
set -a && source .env && set +a
npm run compose:up
npm run demo:start
```

等待就绪（约 1~2 分钟）：

```bash
until curl -sf http://127.0.0.1:18080/api/bootstrap/health >/dev/null; do sleep 3; done && echo ready
```

若演示数据不存在或不完整：

```bash
npm run demo:seed && npm run demo:check
```

`npm run demo:check` 必须输出 `demo data verification passed`。**如果这一步就失败，停止测试并报告**——说明环境本身有问题，后续用例结果不可信。

### 1.2 访问地址

| 用途 | 地址 |
| --- | --- |
| 演示环境前端（**测试用这个**） | http://127.0.0.1:15173 |
| 演示环境后端健康检查 | http://127.0.0.1:18080/api/bootstrap/health |

打开首页会看到「选择登录入口」，四个入口：医生端 / 客服端 / 生产端 / 管理端。**必须从对应入口登录**，账号与入口不匹配会被拒绝（这本身是用例 S-01）。

> ⚠️ 本章为 `[写操作]`，会真实改变数据。**执行前先确认要不要做**——做完之后演示数据状态会变，需要重新 `npm run demo:seed` 才能恢复。

| ID | 步骤 | 预期 |

## 9. 已知不可测 / 已知失败项

**执行到以下用例时按本章判定，不要当成新发现的缺陷。**

### 9.1 新需求未实现（A-11 / A-12 / A-13 / A-14）

客户在《四端角色职责与权限确认清单》中新增的三项需求，以及按岗位分配权限的可操作界面，**当前均未实现**：

| 项 | 状态 |
| --- | --- |
| 账号交接（离职账号转新同事并保留服务记录） | 未实现 |
| 收货人员 / 发货人员岗位 | 未实现 |
| 组长层级（管理员>经理>主管>组长>普通员工） | 未实现 |
| 按岗位分配菜单/权限的可操作界面 | 底层权限码与数据范围已在后端生效，但**缺完整管理 UI**，管理端只能只读查看 |

判定：`已知未实现`，不计入缺陷数。

### 9.2 AI 相关（D-05 / C-04 / C-05）

AI 是否返回真实回答取决于是否配置了 DeepSeek key：

- 若 `.env` 中 `AI_PROVIDER=langchain-deepseek` 且 `DEEPSEEK_API_KEY` 有值 → 应返回自然语言回答，耗时数秒
- 否则返回确定性桩（模板化固定文本）

**先确认配置再判定**：

```bash
grep -E "^AI_PROVIDER|^AI_DEEPSEEK_ENABLED" .env
```

若为 `deterministic` / `false`，AI 用例判 `BLOCKED-配置`，不是功能缺陷。

### 9.3 需客户数据才能完成的项

以下缺口的输入资料客户尚未提供，相关页面会显示"待报价""待设置"或为空，**属预期行为**：

| 缺口 | 影响 |
| --- | --- |
| CP-002 各产品动态表单最终字段 | 下单表单字段可能与最终业务不符 |
| CP-005 文件上传规则（各产品要传什么文件） | 上传项为通用配置 |
| CP-004 各工序标准工时 | 绩效的工时效率、准时率无法真实核算 |
| CP-003 AI 生产备注正式模板 | AI 生产备注用通用模板 |
| 价格与制作周期 | 全部显示"待报价"，到货时间无法自动推算 |

### 9.4 本环境测不了的项

需要真实服务器才能验证，**不要在本地环境判定这些**：

HTTPS、双实例 WebSocket、真实对象存储 bucket 隔离、签名 URL 15 分钟过期、100MB+ 真实弱网续传、数据库备份恢复、日志留存、监控告警、发布回滚。
