## 当前基准

本基准用于后续接手开发和验收判断。它不是客户签字文件，也不代表真实外部服务、真实密钥、真实 webhook、真实客户模板或客户签收已经完成。

## A 类：一期必须修正

A 类全部纳入一期修正：

- 医生端菜单补齐：看板管理、医生订单、患者管理、支付 / 账单管理、账户设置、线上沟通、医生 AI / 订单助手、通知中心。
- 医生文件边界：不做独立医生文件入口；病例、口扫、图片、处方、设计稿等继续归入订单附件与病例资料链路。
- 医生 AI / 通知 / 沟通边界：AI 用于下单引导、缺失提醒、查订单和常见问题；通知中心只放系统提醒；沟通中心处理聊天和附件。
- 客服端七大模块：订单、沟通、客户、产品、配送、账单、外协。
- 生产端命名修正：删除工作单；生产中改为生产异常；物料异常改为物料管理；代问异常统一为待问异常。
- 管理端 / Manager / Admin：作为最高权限总览，后续再按岗位分配菜单和数据范围。

## B 类：一期基础版增强

B 类纳入一期基础版，不扩成复杂经营分析系统：

- 客服统计：翻译待审、账单超期、本月 / 上月对比、订单数量 / 件数、十大客户排名。
- 生产统计：生产异常、待问异常、员工异常、部门今日 vs 上月平均、返工率、出货率、完成率。
- 质量与返工：内返 / 外返拆分，记录原因、责任、处理结果和基础统计。
- 账单物流：一期只做账单、付款状态和物流信息展示 / 人工维护，不接真实支付网关或物流平台 API。
- 外协：一期只做基础记录入口和状态；完整外协成本核算另行估算。

统计默认口径：

- 销量先按订单数量 / 件数，不按金额。
- 十大客户先按订单数量 / 件数排名。
- 上月平均按上月自然月日均。
- 数据不足时显示暂无或 0，不伪造演示数据。

## C 类：入口 / 台账 / 预留，不做完整闭环

C 类保留当前已实现的基础台账、记录和入口，不继续扩成一期完整管理闭环：

- 设备管理：保留设备档案、状态、维护记录和设备事件基础台账；不做设备联网、自动采集、自动报工、完整保养审批流。
- 物料管理：保留物料缺失 / 不符 / 处理进度基础记录；不做完整库存、采购、供应商协同或 WMS。
- 安环管理：只做入口或简单记录；不做完整安全、环保、现场规范审批闭环。
- 成本管理：只做成本记录入口；不做财务级成本核算、发票、付款、对账或自动成本分摊。
- 奖惩模块：不进一期核心开发；既有基础记录可保留，但不作为工资发放结果，不做薪酬结算或复杂审批引擎。
- 行政 / 财务：只做架构预留，不开发完整模块。
