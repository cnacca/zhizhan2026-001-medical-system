本清单用于收口 Task 8 中仍由客户 / PM 决策阻塞的上线项。它不是签字记录，不代表任何事项已经确认；所有默认方案都只是开发侧建议，必须由客户或 PM 书面确认后才能改成 `CONFIRMED`。

## 使用规则

- 每个确认项必须有确认项编号、确认主题、当前默认方案、负责人、期望确认日期、当前状态、未决风险和推荐验收方式。
- `BLOCKED` 表示必须等待客户 / PM 决策，不能仅靠开发关闭。
- `PROPOSED_DEFAULT` 表示已有开发侧默认方案，但仍未签字。
- `CONFIRMED` 只能在客户 / PM 书面确认后使用，并同步更新 `PROJECT.md`、`DECISIONS.md`、OpenAPI、验收矩阵和相关任务文档。
- 任何真实密钥、生产账号、客户私有数据和合同商务信息不得写入本清单。
