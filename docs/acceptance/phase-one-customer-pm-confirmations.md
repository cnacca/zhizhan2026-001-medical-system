# 一期客户 / PM 确认与外部输入分类清单

状态：ACTIVE / 2026-07-15 校正版。

本清单以 PRD V2.0（2026-07-04）和 2026-07-06 已确认范围基准为准，覆盖 2026-07-05 旧 DRAFT 中“CP-001 到 CP-009 全部逐项书面确认”的口径。历史编号继续保留，便于追溯；它们不再都代表产品决策或签字阻塞。

严格按 PRD 计算：**待客户 / PM 确认 2 项，PRD 明确要求逐功能签字 0 项，客户提供资料 1 份，标准工时业务数据 1 包（PRD 未指定提供方，由项目方指定负责人协调）。**项目交付时应在原验收表38项、2026-07-06 A/B/C 表外范围、跨项门禁、上线 readiness 与真实交付证据全部关闭后形成一份总体验收记录，不把38项测试误算为38次签字。

Task 8 仍保持 NOT_READY。原因应按真实的本地实现缺口、外部输入、真实环境执行和最终验收证据分别记录，不能继续统一写成“等待客户 / PM 签字”。

尚未发生的客户培训、真实环境执行和总体验收，其负责人、日期、记录编号与结果仍为待填写；这里的“待填写”是后置证据状态，不是开发前置签字。

## 分类规则

- `PENDING_CONFIRMATION`：PRD 明确要求 PM / 客户确认的产品参数。
- `CONFIRMED_BASELINE`：PRD 或 2026-07-06 基准已确定，直接按基准开发；如要改变才走范围变更。
- `CUSTOMER_INPUT_REQUIRED`：客户提供模板或资料，不是需求签字。
- `BUSINESS_DATA_REQUIRED`：需要真实业务数据；PRD 未指定提供方时，由项目方指定负责人协调，不是需求签字。
- `OUT_OF_PHASE_ONE`：不属于一期 P0；只有新增范围时才评估。
- `DELIVERY_EVIDENCE_PENDING`：开发完成后的培训或最终验收证据，不是开发前置决策。
- `EXTERNAL_ENV_EVIDENCE_PENDING`：真实环境部署、联调和运行证据，不是产品需求确认。
