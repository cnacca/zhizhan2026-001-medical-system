## 本次修正

### 种植类修复

- 两条取模路线均在“种植入货检”之前完成，并在该节点汇合。
- “种植配基台”位于成品基台 / 个性化基台分叉之前。
- 成品基台路线为：
  `种植配基台 → 成品基台 → 客服定基台 → 种植上部冠设计`。
- 个性化基台路线为：
  `种植配基台 → 个性化基台 → CAD入货检 → CAD设计 → CAD切削基台 → 种植研磨基台 → 种植上部冠设计`。
- 成品基台路线不再错误执行个性化基台 CAD 制作节点。

### 贴面修复

- CAD 切削路线独占其自己的
  `上釉 → 抛光 → 质检出货`。
- CAD 传统切蜡路线独占另一组
  `上釉 → 抛光 → 质检出货`。
- 两条路线只在“等待出货”处汇合，不再连续执行两套收尾节点。

### 精密附件

- 原文没有印模 / 口扫分支，活动定义改为 `intake_branch=NONE`。
- 生产审核不应要求为精密附件虚构一个取模选择。

## 原文排版规范化

- 原文中的折行、孤立箭头和重复排版文字按业务箭头与节点顺序合并。
- 贴面口扫段的“打印模型打印模型”按一个“打印模型”节点处理。
- 不把排版重复当作两道生产工序，不新增原文未出现的业务节点。
- 平台的设计确认门禁、权限、强制入检/出检和订单快照属于系统控制规则，
  不冒充原文生产节点，也不改变本记录中的九条业务路线。
