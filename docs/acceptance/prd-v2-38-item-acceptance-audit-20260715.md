## 38项之外的两条跨项一期硬缺口

以下两条由 PRD 的流程描述确定，但原38行验收表没有单独列出；不得因此漏掉，也不需要客户再次签字：

因此，11.1-08 与 14.4-04 的 `PASS` 只表示各自验收表字面动作已通过，不表示更广的生产时序要求已经关闭；以下任一缺口存在时，整个一期仍不能判定完成。

1. **医生确认设计稿生产门禁**：当前设计稿确认只更新 `DOCTOR_CONFIRMED`，生产流程没有强制等待设计确认。应在生产启动 / 节点激活前增加门禁和测试。
2. **出检通过后再激活后继节点**：当前 `completeNode` 将节点设为 `COMPLETED` 后立即调用 `activateReadyNodes`，出检记录随后才提交。应把需要出检的节点后继激活延后到 `OUT/PASS`，并覆盖 FAIL / 返工路径。
