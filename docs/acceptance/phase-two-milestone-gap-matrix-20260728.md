## 已冻结、不再询问

- 设计任务不设本期独立优先级，按进入时间排序。
- 任一授权组长均可内审，首个有效结果生效并留审计。
- 技工不能主动放弃，任务不自动超时回收；管理员有理由转派。
- RuoYi 使用渐进桥接，不一次性替换现有业务运行时。
- 四份中文图文 PDF 为 M6 必交；视频可选。
- 本期只验收国内诊所、中文界面和 `Asia/Shanghai`。
