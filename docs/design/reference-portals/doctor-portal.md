## 1. 定位

医生端面向诊所医生、前台、护士和诊所管理员。它的视觉身份是深海军蓝侧栏配亮蓝操作色，信息密度低于客服端和生产端，重点突出订单进度、待回复事项、设计审核、患者和账单。

正式实现不得暴露生产内部工序人员、工时、绩效、返工责任等字段。参考 HTML 中的演示账号和宽松密码逻辑只能作为状态参考。

## 3. 页面拓扑

| 页面 ID | 菜单名称 | 主要内容 |
| --- | --- | --- |
| `page-dashboard` | Dashboard | 统计卡、Action Required、到货追踪、延迟提醒、月度表现 |
| `page-cases` | My Cases | 筛选器、快捷条件、订单表格、订单详情抽屉 |
| `page-patients` | Patients | 患者列表、患者选择、新增患者 |
| `page-billing` | Billing | 发票、月度账单、状态筛选 |
| `page-settings` | Settings | 诊所信息、账号成员、安全和通知偏好 |
| `page-messages` | Messages | 会话列表、订单消息、输入和快捷回复 |

顶部全局入口包括搜索、语言切换、通知、帮助和 New Order。

## 5. 关键组件

- 登录层：海军蓝全屏背景、居中品牌、Sign In / Demo Accounts 双页签、表单校验和密码显隐。
- 侧栏：品牌区、账号卡片、菜单分组、徽标、底部联系入口；纹理由 CSS 斜线渐变生成。
- 统计卡：桌面端六列，顶部语义色强调线，数值使用衬线字体。
- 订单筛选：展开/收起、状态/医生/产品/标签、起止日期、关键词和快捷条件。
- 表格：hover 高亮、复选框、标签、进度状态和 View 操作。
- 详情抽屉：订单摘要、生产时间线、文件、消息和与当前阶段相关的操作。
- 新订单流程：患者选择、产品分类、牙位/缺失牙选择、文件和提交步骤。
- 通用反馈：Modal、Toast、Tab、Switch、空状态和加载模拟。

## 6. 必须保留的交互

1. 邮箱/密码登录、缺失字段错误、密码显隐和演示账号选择。
2. 角色切换后菜单和操作权限变化。
3. 六个页面导航、顶部标题与激活菜单同步。
4. 全局搜索定位订单或患者。
5. My Cases 的筛选、清空、快捷条件、全选和行选择。
6. 点击订单打开详情抽屉，关闭后回到原滚动位置。
7. New Order 的分步前进/后退、产品分类、患者选择、牙位和缺失牙状态。
8. 新增患者的打开、保存和取消。
9. 设计查看、接受、拒绝、反馈和 3D 查看模拟。
10. 文件预览、消息发送、账单筛选、设置页签和语言切换。

源码中约有 `150` 个内联 `onclick`，不能用“核心按钮能点”代替完整交互盘点。

## 7. 响应式边界

- `<=960px`：统计卡由六列降为三列，双栏内容改为单列。
- `<=700px`：侧栏隐藏，主内容取消左偏移，详情抽屉变为全宽，消息侧栏隐藏。
- 当前像素级桌面基准为 `1440×900`；若要求移动端，必须补 `768px` 和 `390px` 的独立截图与交互验收。
