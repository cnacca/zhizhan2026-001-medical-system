# 三端参考页面使用与像素级验收指南

> 用途：以后进行医生端、客服端、生产端或借鉴三端视觉语言的前端修改时，直接使用仓库内参考文件，不再要求用户重复上传。

## 1. 开始修改前

1. 明确目标端口、目标页面、目标角色、目标视口和本轮交互范围。
2. 阅读 [SOURCE_MANIFEST.md](SOURCE_MANIFEST.md) 并核对目标 HTML 的 SHA-256。
3. 阅读对应端口规范：医生端、客服端或生产端。
4. 对未写入规范的细节，直接查看权威 HTML；不要凭记忆补齐。
5. 先记录当前实现截图和差异，再修改业务代码。

本目录是设计基线，不自动授权修改业务范围、权限模型或真实数据。

## 2. 本地研究方式

可从项目根目录启动只读静态服务：

```bash
cd frontend/public/reference
python3 -m http.server 4173 --bind 127.0.0.1
```

参考地址：

- `http://127.0.0.1:4173/doctor-portal.html`
- `http://127.0.0.1:4173/cs-portal.html`
- `http://127.0.0.1:4173/factory-portal.html`

三个文件共享同一来源时会通过 `localStorage` 联动。若要测试干净状态，应使用隔离浏览器上下文或明确重置原型数据；不能清除用户真实浏览器数据。

## 3. 实施顺序

1. 外壳：侧栏、顶栏、页面背景、内容容器和响应式边界。
2. 令牌：字体、颜色、间距、圆角、边框、阴影和动画曲线。
3. 通用组件：按钮、输入、选择器、表格、卡片、Badge、Tab、Modal、Drawer、Toast。
4. 页面：按页面拓扑逐页复刻默认状态。
5. 角色：补齐菜单、数据范围和操作权限差异。
6. 交互：筛选、输入、选择、滚动、开关、弹窗、抽屉、上传、打印和跨端状态。
7. 业务接入：把原型数组与 `localStorage` 替换为真实 API、WebSocket 和权限校验。
8. 验收：静态检查、构建、真实浏览器路径、同尺寸截图和差异记录。

## 4. 视觉验收矩阵

| 层级 | 必查内容 |
| --- | --- |
| 视口 | `innerWidth`、`innerHeight`、滚动条宽度、截图像素尺寸 |
| 外壳 | 侧栏宽度、顶栏高度、吸顶/固定位置、内容左偏移 |
| 字体 | 字体族、字号、字重、行高、中文回退、数字宽度 |
| 盒模型 | 宽高、padding、gap、margin、边框、圆角 |
| 颜色 | 背景、正文、次级文本、语义色、透明度 |
| 效果 | 阴影、渐变、纹理、模糊、动画时长和曲线 |
| 内容 | 文本换行、表格列、状态标签、图标、SVG、Emoji |
| 滚动 | 页面、表格、抽屉、弹窗和看板的滚动边界 |

## 5. 交互验收矩阵

每个可操作元素至少记录：

- 所属页面和角色；
- 默认、hover、focus、active、disabled 和 loading；
- 触发方式；
- 可见结果；
- 状态或数据变化；
- 关闭、撤销或返回路径；
- 权限不足、空数据、错误和超时结果；
- 是否产生外部动作，例如物流网站、打印或下载。

## 6. 截图与差异规则

- 桌面默认基准：`1440×900`。
- 参考图和实现图必须使用同一浏览器、同一缩放、同一字体环境和同一实际像素尺寸。
- 截图前记录 `window.innerWidth`、`window.innerHeight` 和滚动条宽度。
- 建议文件名：`<portal>-<page>-<role>-<state>-<width>x<height>.png`。
- 尺寸不同的图片不得直接做像素差异图。
- 动态时间、Toast、光标、滚动条和动画中间帧应固定或在报告中标注。

## 7. 允许差异与禁止差异

允许差异必须有书面理由，例如：

- 真实中文文案导致的宽度变化；
- 真实业务数据数量、日期和状态变化；
- 正式认证替代演示账号；
- API、WebSocket、对象存储和权限校验替代 `localStorage`；
- 无障碍或安全要求带来的必要调整。

以下不能以“业务差异”解释：

- 错误的侧栏、顶栏、卡片、抽屉尺寸；
- 未实现 hover、focus、打开、关闭和状态反馈；
- 角色只隐藏菜单但接口仍越权；
- 用风格不一致的图标库替换原有 SVG、Emoji 或 CSS 图形；
- 参考页存在的状态被省略且未记录；
- 通过绕过登录、数据范围或文件校验获得演示效果。

## 8. 完成定义

只有同时满足以下条件，才可声明某个端口或页面完成像素级复刻：

- 源文件哈希已核对；
- 目标页面、角色和状态范围明确；
- 视觉矩阵和关键交互矩阵通过；
- 真实浏览器完成点击、输入、筛选、滚动和开关路径；
- lint、typecheck、build、测试或对应检查通过；
- 参考图、实现图和差异结论已保存；
- 允许差异、未覆盖项和风险已列出；
- 认证、授权、数据范围、文件访问和医生端脱敏没有被削弱。
