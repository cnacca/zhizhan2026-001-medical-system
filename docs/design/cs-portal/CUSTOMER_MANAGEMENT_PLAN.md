# 客服端客户管理页面确认稿

> 状态：业务方案已确认；前端功能重构、HTML像素校准及真实浏览器验收已完成；后端能力仍有缺口
> 确认日期：2026-07-18
> 菜单位置：客户管理
> 权威视觉参考：客服端 `page-clients / Client Management`

## 1. 确认结论

客户管理按参考 HTML 的业务口径实施：

1. 一个客户就是一家诊所，医生、前台、护士和诊所管理员账号归属诊所；
2. 客服经理管理全部客户，高级客服只管理分配给自己的客户；
3. 普通客服和翻译人员不显示客户管理菜单；
4. 客户卡片和详情同时保留“销售负责人”与“客服负责人”；
5. 患者不作为客户档案独立管理，只能在有权限的订单中查看。

## 4. 新增客户

按参考 HTML 保留四步创建流程：

```text
1. 诊所基本信息
   诊所名称、编号、国家、地址、电话、邮箱、销售负责人、客服负责人
            ↓
2. 商务条款
   结算方式、信用额度、账期、合同日期、折扣、价格等级、合作产品
            ↓
3. 医生/成员资料
   姓名、岗位、登录邮箱、电话、账号开通申请
            ↓
4. 检查并创建
   确认诊所、商务条款、负责人和账号后一次创建
```

正式实施保留参考页的步骤和视觉，但第四步只创建诊所业务档案、医生/成员资料及账号开通申请，不在客服端直接创建登录凭据。系统管理员在管理端批准并创建账号后，系统使用一次性邀请或强制首次登录改密机制，任何页面都不得持久化或重复显示明文密码。

## 5. 卡片信息和风险提醒

每张客户卡片显示：

- 诊所名称、国家/地区和客户状态；
- 销售负责人和客服负责人；
- 月结或按单付款政策，以及对应的发货规则；
- 累计订单、本月订单、年度金额和待收款金额；
- 合同到期日和最后下单时间；
- 欠款、合同续签和沉默风险标签；
- 客户详情、价格、合同、账单提醒和重新激活等与当前状态相关的操作。

顶部风险提醒使用真实合同、账单和订单时间数据计算，不使用演示标记。具体收款、调价、合同变更和发货操作仍进入对应业务页面。

## 6. 客户制作偏好规则

- 客户偏好仅作为新订单的默认参考；
- 当前订单明确指示的优先级高于诊所偏好；
- 两者冲突时必须显示差异提醒，不得静默覆盖；
- 修改诊所偏好不得反向修改已创建的历史订单。

## 7. 角色和数据范围

| 角色 | 菜单可见性 | 数据范围 | 页面操作 |
| --- | --- | --- | --- |
| 客服经理 | 可见 | 全部客户 | 新增诊所、编辑档案、维护医生/成员资料、提交账号开通申请、维护偏好、商务条款和负责人 |
| 高级客服 | 可见 | 分配给自己的客户 | 维护诊所业务资料、偏好和商务条款，查看医生/成员与账号状态；不能管理登录安全 |
| 普通客服 | 不可见 | 无客户管理列表权限 | 只在订单和问单中查看必要的诊所摘要 |
| 翻译人员 | 不可见 | 无客户管理列表权限 | 只在翻译任务中查看必要的诊所摘要 |

参考原型只在前端隐藏菜单，并未真正将高级客服的客户卡片限制为所分配客户。正式实施必须在列表、详情、导出和所有写入接口统一执行后端数据范围校验。

## 8. 页面联动

| 客户管理操作 | 去向/结果 |
| --- | --- |
| 查看订单记录 | 点击后进入订单详情 |
| 查看最近问单 | 进入对应订单的问单会话 |
| 查看价格 | 展示该客户真实价格等级和已授权价目 |
| 查看合同 | 展示合同期间、状态和授权的合同资料 |
| 账单提醒 | 进入或调用账单管理的真实提醒流程 |
| 已停用客户 | 保留历史订单、账单、消息和审计记录，不物理删除 |

## 9. 当前系统缺口与后续实施项

以下缺口已记录，但不在本轮方案讨论阶段实施：

1. 当前顶层角色只有 `CS`，没有客服经理、高级客服和普通客服的岗位/权限层级；
2. 当前客户列表对 CS 返回全部诊所，没有客户分配和数据范围；
3. 当前诊所档案只有名称、联系人、电话、状态和偏好数，缺少国家、地址、邮箱、销售/客服负责人等字段；
4. 当前没有销售岗位和销售负责人分配，实施时应增加真实字段；未分配时显示“未分配”，不使用演示姓名；
5. 当前缺少商务条款、信用额度、合同、价格等级、诊所级结算政策，以及医生/成员资料、账号开通申请和账号状态的联动；
6. 当前新增诊所只允许管理员创建，与目标“客服经理创建业务档案、系统管理员管理登录账号”的权限拆分尚未对齐；
7. 当前客户页是简化的列表+偏好工作区，尚未实现参考页的风险提醒、双列卡片、结算政策带、详情弹窗和四步新建流程；
8. 当前账单和订单数据可作为部分汇总来源，但合同到期和沉默风险仍需新增真实数据与规则。
