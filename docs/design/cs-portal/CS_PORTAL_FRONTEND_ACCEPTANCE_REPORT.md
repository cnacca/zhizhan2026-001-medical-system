### 6.3 真人点击与只读自动回归

真实浏览器逐页执行了以下路径：

1. 逐一点击工作台、订单管理、信息审核/翻译、设计稿管理、问单沟通、客户管理、产品管理、账单管理、配送管理、外协管理、设置与账号；
2. 打开并关闭订单、设计稿、客户、产品、账单、配送、外协首条真实记录的详情抽屉；
3. 切换翻译任务标签、订单和业务筛选、设置页全部页签，以及按单/月结账单；
4. 在问单沟通点击“设计确认/资料核对中”快捷回复，确认只填入输入框后清空，没有点击发送；
5. 打开通知预览与通知中心、帮助中心及全部帮助分类；
6. 从顶栏输入订单关键词进入全局搜索，再点击结果打开对应订单详情；
7. 自动化脚本在登录后拦截并记录所有同源 `POST / PUT / PATCH / DELETE`，本轮 `blockedMutations=[]`，确认验收没有写入业务数据；
8. 最终报告中 `consoleErrors=[]`、`pageErrors=[]`，14 个页面/入口的横向溢出检查均通过；另记录 3 条 Google Fonts 网络连接中断警告，页面按基线使用 `PingFang SC / Songti SC` 回退字体，不计为应用运行错误。

### 6.4 验收中发现并修复的问题

1. 信息审核/翻译工作区会被内容撑高到约 `1252px`；已固定为参考稿的 `764px`，列表和正文改为内部滚动；
2. 表格工具栏偏高；已校准为 `49px`；
3. 详情抽屉头部和宽度不稳定；已统一为 `540×900px`、固定 `60px` 头部基线；
4. 客服端 WebSocket 在本地工作树非默认端口经 Vite 代理时返回 `403`；根因是开发代理转发的 `Origin` 与后端允许来源不一致，已只在本地 `/ws` 开发代理中移除该转发头，后端 token 校验和生产环境来源配置均未修改；修复后整套冒烟的控制台与页面错误均为 0；
5. 冒烟脚本最初以登录页隐藏标签判断登录成功，并只保护 `/api/**` 写请求；已改为以真实侧栏和工作台为成功条件，同时保护全部同源写请求，并按真实接口响应等待数据或明确空态。
