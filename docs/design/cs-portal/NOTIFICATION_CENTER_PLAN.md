# 客服端通知中心页面重构确认稿

> 状态：业务方案已确认；前端功能重构、HTML像素校准及真实浏览器验收已完成；后端能力仍有缺口
> 确认日期：2026-07-18
> 参考边界：只有顶栏 `32×32px` 通知铃铛和 `7px` 红点直接映射参考 HTML；预览弹层与完整通知页均为项目扩展

## 1. 设计结论

通知中心采用“顶栏通知预览弹层＋完整通知中心页面”的两层结构：

1. 左侧菜单不增加“通知中心”；
2. 顶栏铃铛是全局入口，未读时显示参考页红点；
3. 点击铃铛先打开最近通知弹层；
4. 点击“查看全部通知”进入完整通知中心页面；
5. 通知中心只负责提醒和业务定位，不在本页直接处理订单、审核设计稿、回复客户或修改配送；
6. “已读”只表示当前账号看过通知，不代表对应业务已经处理完成；
7. 每个账号只能读取、标记自己的通知，不能查看其他客服的通知。

## 2. 依据与参考边界

客服端参考 HTML 顶栏包含通知铃铛和未读红点，但没有通知弹层或完整通知页面，因此不存在可一对一复刻的通知中心主体。

当前项目已经具备：

- 当前账号通知列表；
- 当前账号未读数量；
- 单条标记已读；
- 全部标记已读；
- WebSocket 实时推送后重新加载通知；
- 事件类型、订单 ID、订单号、脱敏通知文案和时间。

因此页面主体复用客服端参考页的紧凑筛选、语义颜色、纵向卡片和页头结构，业务数据必须来自当前项目通知接口，不使用参考原型静态数据。预览弹层和完整页面只能标注为“复用参考组件语言的项目扩展”，不能声称存在一对一 HTML 像素页面。

## 3. 页面职责边界

| 页面 | 职责 |
| --- | --- |
| 工作台 | 汇总需要关注的业务数量和状态 |
| 通知中心 | 按时间记录发给当前账号的事件提醒 |
| 问单沟通 | 与客户进行真实会话 |
| 订单、设计稿、账单、配送、外协页面 | 处理对应业务并维护真实业务状态 |
| 设置与账号 | 维护个人通知偏好 |

通知被阅读后，目标订单、问单、设计稿、配送或外协事项仍按自己的业务状态显示为待处理、异常或已完成。

```text
                                      │                                  │
                                      │ ○ 账单已上传                    │

                                      │                                  │
                                      │ ○ 外协任务即将超时              │
                                      │   OUT-2026... · 3小时前         │
                                      ├──────────────────────────────────┤
                                      │ [全部标为已读]    [查看全部通知] │
                                      └──────────────────────────────────┘
```

弹层规则（项目扩展尺寸，不是参考 HTML 原生弹层）：

- 宽度约 `360px`，最大高度约 `420px`；
- 展示当前账号最近 5 条通知；
- 未读通知使用紫色圆点和浅紫背景，已读通知使用灰色圆点；
- 红点只在存在未读通知时显示，不使用静态装饰数字；
- 点击一条通知会标记已读并定位到对应业务；
- 点击弹层外区域关闭；
- “全部标为已读”只更新阅读状态；
- 弹层不提供回复、审核、删除或修改业务数据的操作。

## 6. 通知分类与目标页面

| 通知分类 | 典型事件 | 点击目标 |
| --- | --- | --- |
| 订单与资料 | 新订单进入、客户补充资料、订单审核变化 | 订单管理或信息审核/翻译 |
| 问单沟通 | 客户回复、消息待审核、当前账号被提及 | 问单沟通对应会话 |
| 设计稿 | 新设计稿、内部审核、客户确认或驳回 | 设计稿管理对应订单与版本 |
| 账单配送 | 账单生成、付款变化、发货和配送异常 | 账单管理或配送管理 |
| 外协 | 即将超时、已经超时、外协异常或已返回 | 外协管理对应批次 |
| 系统 | 智能服务预算和系统风险 | 有权限时进入智能服务页面 |

当前项目已经产生或识别的主要事件包括：

- `AI_BUDGET_EXCEEDED`；
- `ORDER_APPROVED`、`ORDER_REJECTED`；
- `MESSAGE_PENDING_REVIEW`、`MESSAGE_RECEIVED`、`MESSAGE_REVIEW_REJECTED`、`MESSAGE_MENTIONED`；
- `DESIGN_DRAFT_UPLOADED`、`DESIGN_DRAFT_CS_APPROVED`、`DESIGN_DRAFT_CS_REJECTED`、`DESIGN_DRAFT_CONFIRMED`、`DESIGN_DRAFT_REJECTED`；
- `BILL_UPLOADED`、`PAYMENT_RECORD_CREATED`、`PAYMENT_STATUS_UPDATED`；
- `ORDER_SHIPPED`；
- `REWORK_CREATED`、`REWORK_CLOSED`。

所有正式展示名称使用中文业务词句，不向用户显示事件代码。

## 7. 点击与定位规则

点击通知时按以下顺序处理：

```text
点击通知
   ↓
校验通知属于当前登录账号
   ↓
标记该条通知为已读
   ↓
根据事件类型确定目标页面
   ↓
根据 order_id、会话、设计稿版本或外协批次定位具体记录
   ↓
再次校验目标业务数据范围
   ↓
打开具体详情
```

如果目标记录已经不存在、当前账号无权访问或通知缺少定位信息：

- 保留通知正文；
- 显示“相关记录当前不可访问”；
- 不绕过数据范围；
- 不退化为打开其他客户或全部订单列表。

## 8. 阅读状态与业务状态

通知中心只维护：

- 未读；
- 已读。

不增加“已处理”状态。业务是否已经处理必须读取目标页面的真实状态。

| 用户动作 | 通知变化 | 业务变化 |
| --- | --- | --- |
| 打开通知 | 未读变为已读 | 不改变 |
| 全部标为已读 | 当前账号所有未读通知变为已读 | 不改变 |
| 在问单沟通回复客户 | 可保持已读 | 会话状态按真实业务更新 |
| 在设计稿管理完成审核 | 可保持已读 | 设计稿状态更新 |
| 在配送或外协页面解决异常 | 可保持已读 | 异常状态更新 |

## 9. 筛选、搜索与空状态

完整页面支持：

- 全部/未读切换；
- 通知分类；
- 订单号、批次号和通知正文搜索；
- 最近 7 天、30 天、90 天或自定义时间；
- 分页；
- 手动刷新。

空状态分别显示：

- 当前账号暂无通知；
- 当前筛选下暂无通知；
- 通知加载失败，请重新加载；
- 实时提醒暂不可用，仍可手动刷新。

界面使用“实时提醒已连接/暂不可用”，不直接向客服展示 WebSocket 技术术语。

## 10. 权限和脱敏

- 所有岗位只能查询本人的 `user_notification`；
- 单条已读和全部已读只能更新本人记录；
- 通知正文使用面向接收人的脱敏文案；
- 医生端通知不得包含内部状态、生产备注、工序员工、绩效和责任分类；
- 客服端通知仍需应用客户、订单和消息数据范围；
- 普通客服不能通过系统通知进入智能服务治理页面；
- 系统管理员查看本人系统通知，不默认查看其他用户通知；
- 通知跳转必须重新校验目标业务权限，不能只依赖通知已经投递。

## 11. 明确不做的功能

- 不把通知中心做成另一套待办系统；
- 不在通知中心直接回复问单；
- 不在通知中心审核订单或设计稿；
- 不在通知中心修改账单、物流或外协状态；
- 不提供删除或修改通知内容；
- 不把全部已读理解成批量完成业务；
- 不展示其他账号的通知；
- 不使用静态未读数、演示订单号或虚构提醒；
- 不在邮件、短信或企业微信未接入时伪装发送成功。

## 12. 当前实现缺口

以下缺口已记录，但不在本轮方案讨论阶段实施：

1. 当前顶栏铃铛直接进入通知页面，没有最近 5 条预览弹层；
2. 当前完整页面只有最近 50 条纵向列表，没有分类、搜索、日期筛选和分页；
3. 当前通知响应只有事件、订单、文案和时间，缺少统一分类、优先级、操作类型和精确目标定位字段；
4. 当前通知行只能标记已读，不能按事件打开对应订单、会话、设计稿或业务批次；
5. 当前部分真实事件没有匹配中文映射，会退化显示为笼统的“业务通知”；
6. 当前没有新订单、配送异常、外协超时和外协异常等完整通知事件；
7. 当前没有按事件保存客服个人通知偏好的接口；
8. 当前部分通知投递按顶层角色执行，尚未完整应用未来的客服岗位层级和客户分配范围；
9. 当前 AI 预算超限通知会投递给 `ADMIN / CS`，实施岗位层级后需要收窄到有治理权限的账号；
10. 当前没有通知保留周期和历史归档口径，第一期不提供删除功能。

## 13. 实施边界

- 通知入口、页面结构、状态和权限方案已经冻结，当前只执行前端 HTML 像素校准；
- 顶栏铃铛和红点按客服参考页像素级构造；
- 通知弹层与完整页面必须使用同一真实未读数量和通知数据源；
- 通知已读操作必须幂等；
- 点击跳转必须定位具体记录并重新校验权限；
- 通知偏好继续归属“设置与账号”，不在本页重复维护；
- 像素校准完成后重新进行顶栏入口、预览弹层、完整页和返回状态验收。
