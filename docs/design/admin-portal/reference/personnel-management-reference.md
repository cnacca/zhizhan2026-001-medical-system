## 设计理由

人员管理同时包含导航、统计、标签、筛选、表格、状态和职责设置入口，是最能检验整套管理端设计语言的页面。页面采用克制的深蓝侧栏、白色数据面板和单一管理蓝强调色；信息密度高于医生端，但保留三个参考端共同的浅灰背景、圆角卡片、状态胶囊和右侧抽屉交互。界面文字从实际使用者的角度说明“能做什么”和“负责什么”，不向用户暴露后端字段、英文角色代码或权限系统术语。所有图标均为同一套内联线性 SVG，不使用 Emoji、外部图标或装饰性渐变。
