# 管理端页面拓扑

## 设计边界

- 工作台业务内容保持现状，只统一侧栏、顶栏和管理端品牌外壳。
- 设备管理、物料管理、安环管理、成本管控保留独立入口，业务内容不扩展。
- 固定 9 条工艺链只读查看，不提供新增、编辑、删除或拖拽。
- 人员级别统一使用中文：管理员、经理、主管、普通员工。
- 人员管理使用单页名单与人员抽屉，不再拆成“用户管理 / 角色权限 / 组织岗位”三页签。
- 界面文案只说明用户能查看或处理什么，不展示后端字段、阶段编号或技术治理术语。

## 页内标签

| 一级入口 | 页内标签或辅助入口 |
| --- | --- |
| 订单管理 | 订单列表、文件资料 |
| 沟通中心 | 消息处理、沟通管理 |
| 工艺生产 | 工序进度、员工派工；“查看固定工艺链”打开只读抽屉 |
| 人员管理 | 单页人员名单；左侧组织筛选；账号、组织归属和职责权限合并到人员抽屉；“部门与岗位”使用独立弹窗或抽屉 |
| 产品配置 | 动态表单、返工字典 |
