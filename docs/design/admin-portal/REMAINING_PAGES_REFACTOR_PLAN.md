## 2. 全局页面顶部规格

所有剩余管理页面统一使用：

- 顶栏高 56px，左侧为“业务分组 / 当前页面”；
- 右侧依次为真实更新时间（有可靠来源时才显示）、全局搜索、帮助、审计通知；
- 标题区左右边距 24px，1280 宽度下可收紧至 18px；
- 标题区包含管理蓝眉题、23px 一级标题、10px 说明和最多两个真实页面级动作；
- 页面级按钮高 34px、圆角 8px；主动作使用管理蓝，次动作使用白底描边；
- 有内部主要视图时使用底部蓝色下划线页签，不使用胶囊页签；
- 没有真实更新时间或真实动作时直接隐藏，不用占位数据或无效按钮补齐视觉。

顶部以当前人员管理实现为对照；只比较顶部几何、字体、按钮、图标、页签和交互状态，不比较页面主体结构。

## 5. 单页执行闭环

每个页面都必须按同一闭环执行：

1. 读取三个参考 HTML 中与本页直接相关的区域；
2. 先建立“管理端区域 → 直接参考 → 真实字段 → 缺失字段”的映射；
3. 保留参考页的信息层级与交互关系，替换为真实管理端数据；
4. 页面顶部按人员管理顶部基线实现；
5. 主体结构按该页业务单独设计，不套人员管理或通用后台模板；
6. 缺失字段显示“暂未提供”，缺失后端写能力则禁用动作并说明；
7. 运行前端构建与静态检查；
8. 使用真实 Chrome 验证 1440×900、1280×800 和关键交互；
9. 与直接参考区域、人员管理顶部并排截图；
10. 用户验收通过后才进入下一页。
