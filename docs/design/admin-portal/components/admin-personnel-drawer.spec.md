# 管理端人员抽屉规格（旧稿，已废止）

> 状态：`SUPERSEDED`
> 当前抽屉只覆盖普通员工账号资料，不能满足人员管理 V2 将账号、组织归属与职责权限合并查看的要求。不得继续作为最终实现依据；新抽屉以 [管理端前端不可偏离实施规格](../IMPLEMENTATION_BASELINE.md) 第 6 节为准。

## 概述

- 目标：`frontend/src/App.vue` 中 `data-testid="admin-personnel-drawer"` 的 Element Plus 抽屉。
- 视觉来源：`personnel-management-concept.html` 的 `.overlay` 与 `.drawer`。
- 交互：点击新增或编辑打开；关闭按钮、取消、遮罩和 `Esc` 关闭；保存调用真实人员账号服务。

## 精确尺寸

- 宽 `418px`，高 `100vh`，右侧进入；内边距 `0 20px`。
- 阴影 `-18px 0 40px rgba(15,23,42,.14)`。
- 遮罩 `rgba(15,23,42,.28)`，z-index 低于抽屉。
- 头部高 `64px`；标题 `15px`；副标题 `9px`。
- 内容分段上下内边距 `18px`，使用 `#edf2f7` 底边框。
- 输入与下拉控件高 `35px`，圆角 `8px`，字号 `9px`。
- 底部操作区高 `68px`，左右 `20px`，固定在抽屉底部。
- 打开过渡 `transform .22s cubic-bezier(.2,.8,.2,1)`；遮罩过渡 `.18s ease`。

## 内容与边界

- 新增：标题“新增人员”，副标题“新成员 · 普通员工”。
- 编辑：标题“编辑人员”，副标题使用真实姓名和当前中文级别。
- 字段：登录账号、人员姓名、初始/新密码、所属部门、岗位。
- 编辑时账号不可修改；新密码留空表示不更改。
- 当前只保存普通员工账号与组织归属；不在抽屉内制作经理/主管的伪保存入口。
- 失败反馈使用中文操作提示，不显示原始技术错误。

## 状态

- 关闭：抽屉位移 `translateX(105%)`，遮罩不可见。
- 打开：抽屉位移 `translateX(0)`，遮罩透明度 `1`。
- 保存中：主按钮显示加载且防止重复提交。
- 保存成功：展示“人员资料已保存”或“人员账号已创建”，并重新加载人员列表。
- 窄屏 `<=760px`：宽度 `100vw`。
