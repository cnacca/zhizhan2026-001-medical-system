## 概述

- 目标代码：`frontend/src/App.vue` 的人员管理路由与 `frontend/src/admin-portal.css` 的人员专属样式。
- 固定参考图：`docs/design/admin-portal/reference/personnel-management-1440x900.png`。
- 可交互参考：`docs/design/admin-portal/reference/personnel-management-concept.html`。
- 三端来源：侧栏、顶栏、卡片、表格、状态胶囊、右侧抽屉分别延续 `cs-portal.html`、`doctor-portal.html`、`factory-portal.html` 在真实浏览器中已确认的共同设计语言。
- 交互模型：页内标签切换、即时筛选、右侧抽屉、真实人员账号保存。
- 视觉原则：复刻参考页的尺寸和状态，人名、数量、部门、岗位、工作数和状态使用真实数据，不复制演示数字。

## 页面结构

1. 人员页头：中文页标、用户视角说明、导出人员、新增人员。
2. 四张人员指标卡：在职人员、正常账号、待处理账号、已设部门。
3. 主工作区：顶部为“用户管理 / 角色权限 / 组织岗位”标签。
4. 用户管理：层级关系带、搜索与三项筛选、人员表格、空状态、页码摘要。
5. 角色权限：中文四级关系、级别选择、可管理人员和可处理工作的用户说明。
6. 组织岗位：真实部门、在用岗位、人数和人员归属。
7. 人员抽屉：新增或编辑普通员工的账号、姓名、密码、部门和岗位。

## 状态与交互

### 标签切换

- 触发：点击“用户管理 / 角色权限 / 组织岗位”。
- 未选中：`#64748b / 680`，指示线透明。
- 选中：`#2563eb / 780`，底部指示线 `#2563eb`。
- 内容：切换真实子路由，侧栏始终保持“人员管理”选中。

### 搜索与筛选

- 搜索即时匹配姓名、账号、部门、岗位和人员级别。
- 部门、人员级别、账号状态三个筛选可组合。
- “重置”同时清空搜索和三项筛选。
- 无结果时隐藏表格行和页码，展示中文空状态。

### 按钮反馈

- 次按钮 hover：边框 `#bfdbfe`，背景 `#eff6ff`，文字 `#1d4ed8`。
- 主按钮 hover：背景与边框 `#1d4ed8`，上移 `1px`。
- 所有可操作元素 `focus-visible`：`2px solid #60a5fa`，偏移 `2px`。
- `prefers-reduced-motion: reduce` 时关闭非必要过渡。

### 真实数据边界

- 管理员可新增、编辑普通员工账号，结果以真实保存响应为准。
- 经理、主管层级只展示已确认的管理关系，当前不提供虚假的保存或成功提示。
- 表格不伪造最近登录时间；没有该信息时显示真实的资料更新时间。
- 异常不直接展示原始技术错误，只告诉用户哪一项未完成和如何重试。

## 响应式

- `1440px`：严格按参考页四列指标、七列表格和 `230px` 侧栏。
- `1280px`：保持参考页双区布局，全局搜索收缩为 `220px`，层级说明列收缩为 `165px`，表格列间距降为 `8px`。
- `<=980px`：参考 HTML 没有此布局且强制最小宽 `1280px`；产品实现沿用管理端已有的顶部紧凑菜单，指标改为两列，表格在卡片内水平滚动。
- `<=760px`：指标单列，页头操作换行，筛选纵向排列，抽屉宽度为 `100vw`。这是用户可用性增强，不冒充参考页原生移动样式。
