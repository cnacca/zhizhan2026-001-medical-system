## 培训讲师检查点

- 先说明本手册只覆盖本地第一增量，不代表完整生产操作手册已经交付。
- 演示时不得使用真实患者、真实订单、真实密钥、真实 webhook、真实服务器地址或客户隐私。
- 医生端必须只展示外部状态和医生可见资料。
- AI 只做草稿、辅助和查询，不自动审核、自动发送或自动医疗判断。
- 客户 / PM 确认项、正式培训签到和签收必须另行记录；本手册不代表客户培训签收完成。

## 通用登录入口

1. 打开前端地址。
2. 在登录页选择医生端、客服端、生产端或管理端。
3. 使用对应角色账号登录。服务端会校验账号角色与入口是否匹配，错入口登录会被拒绝。
4. 登录后先进入工作台，再从左侧菜单进入具体功能。

注意：

- 不要把本地 smoke 账号或示例密码写入客户正式手册。
- 正式环境必须关闭 `X-Bootstrap-*` 本地兼容路径。
- 医生端页面不得展示内部工序、员工、返工、工时、绩效、内部附件或内部备注。

## 医生端

### 新建订单

1. 进入医生端。
2. 打开订单管理 / 新建订单。
3. 选择产品类型，填写动态表单。
4. 需要附件时先创建或选择订单，再通过文件上传入口上传附件并回填 `file_id`。
5. 点击提交订单，订单进入客服审核。

验收关注：

- 文件上传会校验大小、类型和数量。
- 医生只能绑定本人订单下可见且已完成上传的文件。
- 医生端只显示外部状态。

### 我的订单与订单主链路

1. 打开我的订单。
2. 查看订单外部状态、公开消息、设计稿、账单物流和通知。
3. 订单发货后，在账单物流区域查看承运商和运单号。
4. 收到货后点击确认收货，订单外部状态进入完成。

当前限制：

- 付款状态仍需客户 / PM 确认口径。
- 真实物流平台 API 尚未接入。
- 实时自动保存和完整跨设备上传验收尚未完成。

### 设计稿

1. 打开设计稿确认。
2. 查看待确认设计稿版本。
3. 点击预览链接，系统会按文件权限生成短时效签名 URL。
4. 根据实际结果确认或驳回设计稿。

当前限制：

- 三轮驳回 / 重传完整回归仍未完成。
- 在线 CAD 审稿和复杂批注不在一期第一段范围内。

### 账单物流

1. 打开账单物流。
2. 查看账单文件和物流信息。
3. 需要查看账单时获取账单预览链接。
4. 收到货后确认收货。

当前限制：

- 付款状态和账单金额结构化仍未完成。
- 真实物流平台自动同步不在当前第一段范围内。

### AI 助手

1. 打开订单助手。
2. 只询问订单公开进度、账单、物流和医生可见消息。
3. 涉及内部工序、员工、返工、工时、绩效时，系统应返回安全拒绝。

## 客服端

### 客服初审

1. 进入客服端。
2. 打开内部订单 / 客服初审。
3. 选择待审核订单。
4. 查看资料缺失提示。
5. 可生成 AI 翻译草稿，但必须人工确认后才能写入生产备注。
6. 审核通过后进入生产审核；审核驳回后医生可补资料重新提交。

验收关注：

- AI 只生成草稿，不自动审核、自动发送或自动驳回。
- 驳回原因需要面向医生可理解。

### 协同消息

1. 打开沟通中心。
2. 查看待审核消息。
3. 按订单 ID 查看订单消息上下文。
4. 对生产发给医生的消息执行通过或驳回。

当前限制：

- 完整客服 CRM、客户偏好和复杂工单不在当前第一段范围内。
- 消息附件 URL 聚合和生产级通知联动仍需后续验收。

### 设计稿审核

1. 打开内部订单设计稿区域。
2. 选择订单后加载设计稿版本列表。
3. 获取设计稿文件预览链接。
4. 审核通过后医生端可确认设计稿。

## 生产端

### 生产审核

1. 打开生产审核。
2. 选择待生产审核订单。
3. 核对系统按订单产品自动匹配的工序链；若没有匹配链，不得通过审核。
4. 按客户实际提供的资料选择入口路线：STL / PLY 等数字化扫描资料选择“口扫”，实体印模或石膏模型选择“印模”；只支持单一路线的工序链由系统自动锁定。
5. 种植修复选择“成品基台 / 个性化基台”，贴面修复选择“CAD 切削 / 传统蜡型”；其他产品没有额外工艺分支，不填写技术参数。
6. 审核通过后系统生成工序实例快照；资料或路线无法确认时填写驳回原因并退回。

### 派工与任务池

1. 管理员或客服进入派工页面。
2. 选择工序节点并绑定员工。
3. 工人进入我的任务，查看本人 READY / IN_PROGRESS / COMPLETED 任务。

### 入检、工时、出检

1. 工人进入入检 / 出检页面。
2. 对需要入检的节点先提交入检通过。
3. 进入工时记录页面，执行开始、暂停、继续、完成工时。
4. 工序完成后提交出检。
5. 出检通过会推进后续节点；出检失败会创建返工记录。

验收关注：

- 工时按服务端记录计算，暂停段会扣除。
- WORKER 只能查看本人任务和本人绩效。

### 返工终检

1. 打开返工终检。
2. 查看待返工记录。
3. 查看返工影响图，理解返工目标和受影响后续节点。
4. 目标节点重做并出检通过后关闭返工。
5. 具备终检专用权限的账号可生成终检报告。

当前限制：

- 真实电子签章和复杂报告模板尚未接入。
- 医生端不可读取内部终检报告和内部附件。

### 绩效

1. 打开绩效统计。
2. WORKER 默认看本人绩效。
3. ADMIN 可输入员工 ID 查看指定员工绩效。
4. 可使用开始日期和结束日期筛选周期。

当前限制：

- 标准工时配置、完整公式、申诉、导出和工资发放仍未完成。

## 管理端

### 动态表单

1. 打开动态表单管理。
2. 新增、编辑或停用字段。
3. 医生端只读取 ACTIVE 字段。

### 返工字典

1. 打开返工字典管理。
2. 新增、编辑或停用返工原因和责任类型。
3. 关闭返工时只能使用 ACTIVE 字典项。

### 通知中心

1. 打开通知中心。
2. 查看未读通知。
3. 可标记单条已读或全部已读。

### 部署与配置

1. 本地开发使用 `.env.example` 和 `compose.yaml`。
2. 一期部署骨架使用 `deploy/docker-compose.phase-one.yml`。
3. 正式环境真实密钥必须外部注入。
4. 不要提交真实数据库密码、MinIO 密钥、DeepSeek API Key 或 webhook secret。

## 交付验收建议

1. 先运行机器检查。
2. 再按 12 步主链路客户验收版逐项演示。
3. 记录 PASS / PARTIAL / BLOCKED。
4. 对客户 / PM 确认项单独签字，不把开发侧 smoke 结果当成客户确认。
