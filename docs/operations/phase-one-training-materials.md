## 培训边界

- 培训对象：医生端、客服端、生产端、管理端使用者，以及 PM / 客户验收代表。
- 培训材料来源：`docs/operations/phase-one-role-operation-manual.md`、`docs/acceptance/phase-one-main-chain-customer-acceptance.md`、`docs/operations/phase-one-troubleshooting-guide.md`。
- 当前状态：本地模板已准备；真实培训时间、真实参训人、客户 / PM 签收仍为 `待填写` / `待确认`。
- 禁止事项：不记录真实患者、真实订单、真实密钥、真实 webhook、真实服务器地址或客户私有资料。

## 医生端培训

目标：

- 理解医生端只看外部状态。
- 完成新建订单、附件上传、设计稿确认、账单物流查看、确认收货和 AI 订单助手安全边界。

演示路径：

1. 登录医生端。
2. 新建订单并填写动态表单。
3. 上传附件并确认文件状态。
4. 查看我的订单、设计稿、账单物流和通知。
5. 向 AI 助手询问公开状态；演示内部工序问题的安全拒绝。

## 客服端培训

目标：

- 完成客服初审、AI 翻译草稿人工确认、资料缺失检查、沟通消息审核、设计稿审核、账单 / 物流人工状态维护。

演示路径：

1. 登录客服端。
2. 打开客服初审，查看资料缺失提示。
3. 生成 AI 翻译或生产备注草稿，并强调必须人工确认。
4. 审核生产端发给医生的消息。
5. 查看配送管理和异常跟进第一段。

## 生产端培训

目标：

- 完成生产审核、工序实例、派工、任务池、入检、工时、出检、返工、终检和绩效查看第一段。

演示路径：

1. 登录生产端或管理端。
2. 通过生产审核生成工序实例。
3. 管理员或客服派工。
4. 工人处理任务池、入检、开工、暂停、继续、完工和出检。
5. 演示返工影响图和终检报告边界。

## 管理端培训

目标：

- 理解动态表单、返工字典、通知中心、账号权限和部署配置边界。

演示路径：

1. 登录管理端。
2. 查看动态表单管理与产品参数基础维护。
3. 查看返工字典管理。
4. 查看通知中心和未读处理。
5. 强调正式环境不允许本地 bootstrap header、真实密钥必须外部注入。
